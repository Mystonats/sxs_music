# Sword × Staff — Soundtrack

An unofficial fan playlist of the in-game music from **Sword x Staff**.

Open `index.html` in a browser. That is the whole page.

Named kingdom, concert, festival, and seasonal themes sit at the top. Events, battle, menus, and season extras are in collapsed groups below — use search if you want a collab or a fight theme.
